# NexusNet SDKs

Language bindings for NexusNet. Each SDK wraps the Rust core through a stable FFI
boundary. These are delivered in **Phase 8**; see [`docs/roadmap.md`](../docs/roadmap.md).

- `flutter/` — Dart/Flutter bindings.
- `python/` — Python bindings (PyO3 / FFI).
- `cpp/` — C++ bindings over a C ABI.
- A REST API surface is also planned.
