# nexusnet-cli

Command-line interface for inspecting and operating the NexusNet engine. Installs
a binary named `nexusnet`.

## Usage

```text
nexusnet version    # Print the engine version and exit.
nexusnet info       # Resolve configuration from NEXUSNET_* env vars and print it.
nexusnet help       # Print help text.
```

## Status

Foundation established in **Phase 1**. Serving commands (running listeners,
health checks, live stats) arrive alongside the transport layer in **Phase 3**.
