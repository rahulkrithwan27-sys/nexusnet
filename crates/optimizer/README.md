# nexusnet-optimizer

Adaptive, model-driven network optimization for NexusNet.

## Planned responsibilities

- Bandwidth and congestion prediction
- Adaptive packet sizing and compression levels
- Adaptive retry timing and quality
- Predictive scheduling
